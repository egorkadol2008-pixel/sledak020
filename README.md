# СК: Материалы дела

Играбельная первая глава **«Чужие решения»**, версия 0.3. Главный акцент — развитие следователя: карьерные цели, обустройство кабинета, личные деньги и помощь людей, чьё доверие вы заслужили. Пять связанных расследований ведут от исчезнувшей папки к городским контрактам. Игрок собирает материалы, исправляет и подписывает документы, защищает выводы в суде и отвечает за прежние решения.

Это первая большая часть реализации концепции: **5 дел, 32 материала и 15 судебных раундов** с завершением главы. Следующая глава пока не реализована.

## Запуск

Нужны Node.js 20.19+ или 22.12+ и npm. В облачной среде используется Node.js 24. Установка по lockfile:

```bash
cd /workspace/sledak020
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev -- --port 5173
```

Сервер разработки слушает порт 5173. При локальном запуске откройте адрес, напечатанный Vite. В облачной среде работоспособность проверяется браузерными тестами. Если репозиторий находится в другой папке, замените путь в `cd`. Отдельный сервер приложения, база данных и внешние ключи не требуются.

## Проверки

```bash
npm run build
npm test
npm run test:e2e
```

Сборка проверяет TypeScript и создаёт `dist/`. Vitest проверяет правила первого расследования и кампании. Браузерные сценарии Playwright охватывают прохождение, развитие персонажа, сохранения, отложенное последствие взятки и мобильные экраны.

Playwright запускает сервер автоматически. Используется установленный Chromium либо путь из `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Если браузер отсутствует, выполните `npx playwright install chromium`.

## Что реализовано

- **Расследования:** «Последняя папка», «Пепел на складе», «Чужая подпись», «Тихий свидетель», «Цена тишины».
- **Документы и суд:** проверка реквизитов, исправленные версии с сохранением оригиналов, рисованная или текстовая подпись, выбор материалов итогового пакета и три судебных вопроса на дело.
- **Карьера:** 7 навыков, опыт и должности, 4 цели с одноразовыми наградами за завершённые дела, качественную работу, кабинет и круг доверия. Здоровье, стресс, репутация, добросовестность, коррупция и угроза влияют на состояние героя и итог главы.
- **Кабинет и деньги:** 6 работающих улучшений, отдельные личные деньги и служебный бюджет, зарплата и финансирование после дела. Финансовый журнал показывает начальные остатки и операции; записи можно фильтровать по счёту.
- **Люди и последствия:** 4 контакта с диалогами и доверием. При доверии от 50 доступна помощь раз за новое расследование, от 75 её эффект удваивается. Сохраняются поддержка свидетеля, предложения взяток и последующая служебная проверка.
- **Сохранения:** автосохранение, экспорт и импорт всей кампании, перенос сохранения первого прототипа, общий архив документов и решений.

На главном экране нажмите «Продолжить расследование». Первое дело использует подробный рабочий стол исходного прототипа; после его итогового решения вернитесь в кампанию и пройдите суд. Каждое следующее поручение открывается после судебной стадии предыдущего, в том числе при неудачном исходе. Правила новых дел и развития описаны в [руководстве по главе](docs/chapter-one.md).

Прогресс хранится в этом браузере. Экспортируйте JSON через настройки перед сменой устройства или очисткой данных. Сохранения v1 и v2 совместимы с версией игры 0.3. При загрузке старой кампании без финансовой истории журнал начинается с её текущих остатков: прошлые операции не восстанавливаются предположениями. Сохранение v1 автоматически переносится при отсутствии кампании v2; его также можно импортировать вручную. Повреждённый импорт не заменяет текущую игру. Отдельный совместимый первый прототип доступен по пути `/?case=001`; существующая кампания v2 имеет приоритет перед его локальным сохранением.

Режим «Опер», бесконечные процедурные дела, свободное перемещение, управление отделом и полная система романтических отношений пока остаются в концепции. Отношения этой главы — профессиональные и дружеские диалоги с доверием и практической поддержкой. Помощь знакомых не выдаёт доказательства. Подпись сохраняется как изображение или имя без распознавания почерка. Судебная стадия проверяет основания пакета; принятие материалов не равно обвинительному приговору.
